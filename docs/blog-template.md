# Blog Post Template — BairesDev Solutions

Use this template for every blog post. All fields are required unless marked optional.

---

## Frontmatter (saved to CMS fields)

```
title:           [Compelling title, 50–80 chars, keyword near front]
slug:            [url-friendly-slug-from-title]
excerpt:         [2–3 sentence summary, 140–200 chars, includes primary keyword]
category:        [zoho | shopify | ghl | wordpress | ai | uiux | web | ecommerce]
readTime:        [X min]
seo.metaTitle:   [50–60 chars, keyword-rich]
seo.metaDesc:    [140–155 chars, includes keyword + call to read]
imagePrompt:     [Descriptive visual prompt for Gemini Imagen, no text, no people]
```

---

## Post Body Structure

```markdown
[Hook — 1-2 sentences. Start with a problem, stat, or bold claim. NOT "In today's world..."]

[Core problem paragraph — 3-5 sentences explaining the pain point and why it matters]

## [Main Section 1 — e.g. "Why Most [X] Fail at [Y]"]

[2-3 paragraphs. Include a specific example or scenario.]

- [Bullet point if listing 3+ parallel items]
- [Bullet point]
- [Bullet point]

## [Main Section 2 — e.g. "How to [Solve It]: A Step-by-Step Approach"]

[Step-by-step or key points. Use numbered list for sequential steps.]

1. [Step one with explanation]
2. [Step two with explanation]
3. [Step three with explanation]

## [Main Section 3 — e.g. "Setting Up [Feature] the Right Way"]

[Specific, practical guidance. Name real tools, settings, features.]

### [Sub-section if needed]

[Detail]

## [Main Section 4 — e.g. "Common Mistakes to Avoid"]

[At minimum, cover 2–3 mistakes. Can be bullet list or short paragraphs.]

- **[Mistake 1]:** [Explanation of what goes wrong and how to fix it]
- **[Mistake 2]:** [Explanation]
- **[Mistake 3]:** [Explanation]

## [Main Section 5 — e.g. "What Good Looks Like" or "The Results You Can Expect"]

[Close the main body with outcomes, benchmarks, or a summary of the approach.]

## The Bottom Line

[1 paragraph — most important takeaway restated simply.]

If you're looking to [problem topic], BairesDev Solutions can help. We specialise in [relevant service area] for businesses that need results, not just advice. [Contact us](/contact) to talk through your project.
```

---

## Word Count Targets per Section

| Section | Target words |
|---|---|
| Hook | 20–40 |
| Core problem | 60–100 |
| Main sections (×4–5) | 120–180 each |
| Common mistakes | 80–120 |
| Bottom line + CTA | 60–80 |
| **Total** | **900–1,200** |
